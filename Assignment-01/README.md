# VangtiChai

CSE 489 Assignment 1: a Flutter Taka change calculator with a hand-built numeric
keypad, responsive phone/tablet layouts, and Android state restoration.

## Run

```sh
flutter pub get
flutter run
```

## Verify

```sh
flutter analyze
flutter test
flutter build apk --debug
```

See [README.txt](README.txt) for assignment details, screen sizes, SDK requirements,
and the verification record. No additional packages are required.
