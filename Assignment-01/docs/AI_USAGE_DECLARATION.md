**Project:** VangtiChai  
**Course:** CSE 489: Mobile Application Development, Assignment 1  
**Prepared:** 18 October 2026

## How AI Helped Build This Project

I used AI as a learning and development assistant while building VangtiChai.
AI provided step-by-step instructions, explanations, and code-writing guidance
in the following areas:

### 1. Project Setup and File Organization

AI guided me through setting up a Flutter project and understanding its folder
structure. It helped explain where to place Dart source files, how `lib/main.dart`
starts the application, how `pubspec.yaml` is used, and how to separate the screen,
calculation logic, and shared UI constants into appropriate files.

### 2. Android Studio and Installation Guidance

AI provided instructions for installing and configuring Android Studio, the
Flutter SDK, the Dart and Flutter plugins, and Android SDK components. It also
explained how to check the development environment using `flutter doctor` and
how to set up an Android emulator for running the application.

### 3. Installing Dependencies and Running the App

AI explained the commands needed to prepare and run the project, including
`flutter pub get`, `flutter devices`, and `flutter run`. It also provided guidance
on building an Android APK using `flutter build apk --debug` and understanding
setup or installation errors.

### 4. Guidance for Writing Flutter Code

AI helped me understand and write Dart and Flutter code for the numeric keypad,
amount input, CLEAR button, Taka note calculation, and result display. It also
provided guidance on using widgets, updating application state, and arranging
the interface for portrait, landscape, phone, and tablet layouts.

AI assistance supported both learning and implementation; it was not limited to
